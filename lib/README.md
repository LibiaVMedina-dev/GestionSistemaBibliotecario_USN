# Drivers JDBC

Esta carpeta contiene los drivers JDBC oficiales utilizados por PageTurner.

| Motor | Artefacto | Versión | URL JDBC |
| --- | --- | --- | --- |
| MariaDB | `org.mariadb.jdbc:mariadb-java-client` | 3.5.10 | `jdbc:mariadb:` |
| MySQL | `com.mysql:mysql-connector-j` | 26.7.0 | `jdbc:mysql:` |

Los artefactos se descargaron desde Maven Central. Junto a cada `.jar` se
conserva el checksum SHA-256 publicado por el repositorio para poder comprobar
su integridad.
